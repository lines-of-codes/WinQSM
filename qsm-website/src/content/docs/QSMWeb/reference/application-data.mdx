QSM Web store its data at the following location *by default* on various operating systems:

- Linux: `/var/lib/qsm-web`
- FreeBSD: `/usr/local/etc/qsm-web/`
- Windows: `C:\ProgramData\QSMWeb\`
- macOS: The program's current working directory.

## Directory Structure

Similar to the nature of QSM Windows, QSM Web has the following filesystem structure:

<FileTree>

    - config.json Application-wide settings
    - downloads/
    - logs/
    - qbs/ QBS Installation Location
    - servers
        - [server_name]
            - config.qsm.json Server-specific QSM-only configuration
            - ...

</FileTree>

## Changing the data location

You can change where the data folder is located by editing `appsettings.json` and add the `QSM:DataFolder` configuration
key to it, as follows:

```json
  "QSM": {
    "DataFolder": "/abc/def"
  }
```

Or you can use the environment variable `QSM__DataFolder`
